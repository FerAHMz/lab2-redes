# Archivos base del Lab1

Punto de partida provisto por el laboratorio: el cajero automático y el servidor bancario
usados en el análisis de protocolo con Wireshark (Lab1).

- `client.py` — cajero automático original. Base del emisor (`emisor/`).
- `server.py` — servidor bancario original. Base del receptor, portado a Node.js (`receptor/`).

Se conservan sin modificar como referencia. La implementación con capas vive en `emisor/`
y `receptor/`.
